# HAY-WHY Digital Concept Portfolio

A premium responsive portfolio website built with:
- HTML5
- CSS3
- Bootstrap 5.3 (grid/utilities)
- Vanilla JavaScript (ES6+)
- Bootstrap Icons

## Files
- `index.html` — main page
- `css/style.css` — design system and responsive styles
- `js/main.js` — navigation, theme switcher, filters, modal, FAQ, slider and form validation
- `assets/hay-why-logo.png` — supplied HAY-WHY logo

## Run locally
Open `index.html` in a browser, or serve the folder with any simple local server.

## Before launch
1. Replace the portfolio placeholder artwork with your real project images/case studies.
2. Replace the demo email and phone number in `index.html`.
3. Replace the social links in the footer.
4. Connect the contact form to Formspree, Netlify Forms, EmailJS, a custom backend, or another form provider.
5. If you want the supplied logo to be the primary brand mark in the header, crop/export a transparent version of the logo for best results.
